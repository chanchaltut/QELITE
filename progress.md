## What's built (summary)

- **Public site:** Home · Verify (`/verify?cert=…`) · Certifications (13 standards, one page each) · Accreditation & policies · About · Contact & quotes · FAQs · Privacy · Terms. All prerendered for SEO.
- **Certificate verification:** exact-number lookup (spaces, slashes and case are ignored). Statuses: Valid / Suspended / Withdrawn / Expired (expired is automatic). Shows the uploaded PDF, or a digital QELITE certificate if there is no PDF. There is also a report form for suspicious certificates.
- **Certificate design:** an A4 QELITE certificate with a QR code, Q watermark, microprinted border and QELITE seal, following the layout of `ReferencePDFDesigns/`. Long text shrinks to fit the page. Admin → certificate → **Print / save as PDF**.
- **Certification portfolio PDF:** `docs/QELITE-Certification-Portfolio.pdf` (cover, index, 13 specimen certificates, closing page). Rebuild it with `npm run portfolio` in `client/` after changing standards, the certificate design or the issuer details.
- **Brand files (`client/public`):** `qeliteLogo.svg` and `qeliteMark.svg` are white for dark backgrounds; the `Navy` versions are for light backgrounds. They are vector traces of the supplied `qeliteLogo.webp` and `qeliteFavicon.webp`.
- **Admin panel:**
  - Certificate register: add, edit, suspend, withdraw; PDF upload; audit dates auto-calculated; CSV export; "audits due" list; verification counts.
  - Website management with Publish and rollback, Inbox, Users and Audit log.
- **Data safety:**
  - Certificates live only in MongoDB and never go into the website build. Lookups are rate-limited (40 per 10 minutes per IP), and there's no listing or search by company.
  - PDFs are stored privately and only served while a certificate is valid.
  - Only the owner can delete; editors withdraw instead.
  - `robots.txt` blocks AI crawlers.
- **Theme:** navy `#0B1A2E` + white, mint accent `#9DE5C8`, emerald `#0E8064`. All colours are in `client/src/index.css` (`:root`).

## Running locally
```bash
npm run install:all
npm run dev          # website (port 5173, or the next free port; 5173 is often busy on this machine)
npm run dev:server   # API on :4000 — needs server/.env (copy server/.env.example) with a MongoDB URI
```
Tonight's local test database was **in-memory and temporary**. Its sample certificates (QMS/26Q00001 etc.) are gone once it stops. For local work, put a MongoDB Atlas URI (a separate dev database, e.g. `/qelite-dev`) in `server/.env`.
